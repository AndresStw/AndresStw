## 🚀 About Me

I’m a software developer focused on **game development, interactive systems, and real-world digital products**.

I enjoy turning ideas into playable experiences, useful tools, and projects that combine creativity with technical execution. My long-term goal is to build **Axion Studios**, an indie game studio centered on memorable and technically ambitious experiences.

> “Turn ideas into playable games, useful applications, and real projects.” 🎮✨

- Developing web experiences with React and Supabase
- Turning ideas into polished, usable projects
